# JEV 역할 분담 검사: 고정 버전 연구 프로토타입

사용자 요청: JEV 버전을 고정하고 에이전트처럼 역할을 분담해 종합 판단한다. 기존 정상 기준 기반 연구 설계의 다음 실험이며 공개 dinopatch API와 원본 데이터는 변경하지 않는다.

## 구성

- 요청 모델은 `typesafe/jev-1.13`, 응답 모델/공급자도 기록한다. `latest` 및 다른 모델 대체를 사용하지 않는다. 동일 실행 중 응답 모델이 바뀌면 중단한다.
- 관찰·외관·구성 담당은 각각 제한된 측정 상태를 받아 별도 JEV 호출로 판단한다. 이는 같은 모델에 대한 역할 분리이며 독립적인 전문가 투표가 아니다.
- 조정 담당은 저장된 부품 확대, 정합+조도, 로컬 Qwen3-VL-4B 관찰 중 다음 도구를 선택한다. 최대3개 도구, 중복 조회 금지. 선택 뒤 실제 해당 결과만 상태에 추가한다.
- 반증 담당은 근거의 충돌/부족을 점검하고, 종합 담당은 OK/NG/REVIEW와 구조화된 근거 코드를 선택한다. 설명 문장은 코드와 실제 측정값으로 생성하며 JEV의 숨은 추론을 복원했다고 주장하지 않는다.
- 정상 분할 실패만으로 실제 부품 누락을 선언하지 않는다. 없는 관찰, API 실패, 유효하지 않은 출력은 자동 OK로 처리하지 않는다. 최종 JEV 제안과 정책 적용 후 판정을 함께 보존한다.

## 첫 비교

기존 로컬 VLM과 동일한18개 cable 원본(정상2·불량16)의 원본/복합36건을 사용한다. 선택 목록은 호출 전에 저장한다. 정상 수가 매우 작고 이미 관찰한 개발 표본이므로 일반화 성능이나 정밀한 오탐률을 주장하지 않는다.

1. 기존 고정 외관+색상 규칙.
2. 단일 JEV가 모든 저장 관찰을 받은 대조군.
3. 역할 분리 JEV가 추가 검사 결과를 순차 선택하는 구성.
4. 역할 분리 상태에서 모든 추가 검사 결과를 제공한 구성.

역할 분리 실험은 **저장된 도구 결과를 실제로 조회하는 재생 실험**이다. 신규 이미지에 모든 시각 모델을 실시간 호출하는 완성 에이전트와 구분한다. 각 실험군에서 관측한 근거, 호출 수, 비용, 지연, 오탐/미검/보류를 기록한다. 속도보다 정확도에 관심이 있으므로 전부 검사하는 대조군을 유지한다.

## 입력과 검증

JEV에는 공개 cable의 수치 관찰 및 저장 VLM 관찰 텍스트만 보낸다. 이미지 파일, 사용자 산업 이미지, 경로·파일명·정답·합성변환 정답은 보내지 않는다. 시각 모듈의 관측량만 허용 목록으로 추출한다. 라벨은 로컬 평가에만 사용한다.

공식 Decisions API `/api/alpha/decisions` 사용. Choice 구조, 선택지별 확률, 공급자와 응답 버전을 검증한다. 선택 확률0.65 미만이면 정책 보류하되 이 값은 실측 검출 확률이나 보정된 신뢰도가 아니다. API 오류는 기록하고 실행을 멈추며 임의 모델/오프라인 결과로 대체하지 않는다. 최대600호출, 보고된 누적 비용0.50달러 도달 시 추가 호출 중단; 비용 필드가 없으면 중단한다. 마지막 응답 비용만큼 예산을 넘을 수 있어 엄격한 결제 상한이라고 주장하지 않는다.

원문 요청 본문(키 제외)·응답·근거·단계별 선택을 저장한다. 키는 환경 변수 또는 기존 .env에서 런타임에만 읽고 출력/복사하지 않는다. 기존 코드의 provider `data_collection=deny`, `zdr=true` 요청을 유지하며 지원되지 않으면 완화하지 않고 실패로 남긴다.

## 구현 순서

1. 입력 누출 방지, 버전 고정, 응답 검증, 근거 누락 시 보류 테스트.
2. 작은 표준 라이브러리 API 클라이언트와 역할/도구 실행 루프.
3. 저장 관찰 어댑터, 비교 실행, 원문·지표·HTML 기록.
4. 단위 테스트 → 단일 연결 확인 →36건 비교 → HTTP 보고서 확인.

공식 자료: https://openrouter.ai/docs/guides/community/jev 및 https://openrouter.ai/docs/api/api-reference/alphadecisions/submit-a-decisions-request

## 실행 중 확인한 수정

- API 확률이 소수 둘째 자리로 반올림되어 합이0.99인 응답이 있었다. 선택지 수×0.005 범위의 반올림 오차만 허용하고 원래 확률을 재정규화하지 않는다. 단위 테스트로 재현했다.
- 첫 연결은 로그 하위 폴더 생성 누락으로 네트워크 호출 전에 실패했으며 수정했다. 이후 고정 응답 버전 `typesafe/jev-1.13-20260917`을 확인했다.
- 연결이 응답 없이 종료되는 오류가 반복되어, 성공한 동일 요청 본문의 해시가 일치하는 응답을 재사용하는 `--replay-root`를 추가했다. 실패한 실행은 그대로 보존하고 새 실행에서 이어간다. 네트워크 오류에 한해 새 실행 재개를 최대6회 시도하며 HTTP 인증/비용/버전/스키마 오류는 자동 재개하지 않는다. 서버가 응답을 주지 않은 요청은 청구 여부가 불명확하므로 보고 비용은 확인된 usage.cost의 합이다.
- 캐시 응답은 신규 API 비용에 합산하지 않는다. 이전 실행 비용과 새 실행 비용은 별도로 남긴다. 자동 모델 대체나 개인정보 설정 완화는 하지 않는다.
- 독립 코드 검토에서 JEV의 판정과 이유 코드가 모순될 수 있음을 확인했다. JEV의 원래 이유 코드를 보존하되 최종 표시 이유는 검증된 판정·인용 근거로 결정한다. 해당 회귀 테스트를 추가했다.
