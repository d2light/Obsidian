# 어두운 이미지 제외 실험

사용자가 `D:\datasets\waterseal\OK\dark`와 `NG\dark`로 구분한 이미지를
어두운 조건으로 사용한다. 밝음은 자동 밝기 측정 결과가 아니라 `dark` 밖에 있다는 뜻이다.
어두운 정상 51장과 불량 13장은 모두 2025-08-18 촬영이다.
원본은 읽기만 하며 새 데이터셋 사본과 새 모델을 생성한다.

## 비교 조건

이전 실험의 이미지 파일·RGB 해시 및 OK/NG 라벨과 일치하는지 확인한다.
기존 분할을 유지하되, `dark` 이미지가 하나라도 포함된 연속 촬영 묶음은 전체를
검증으로 옮긴다. 학습·보정 표본을 새로 채우거나 다시 섞지 않는다.
이전 정상 학습 252장 중 어두운 28장을 빼서 224장, 보정 98장 중 어두운 13장을
빼서 85장을 사용한다. 이번 데이터에서는 같은 묶음 때문에 추가로 빠진 밝은 이미지는 없다.

| 용도 | 밝은 정상 | 어두운 정상 | 밝은 불량 | 어두운 불량 |
|---|---:|---:|---:|---:|
| 학습 | 224 | 0 | 0 | 0 |
| 임계값 보정 | 85 | 0 | 0 | 0 |
| 검증 | 134 | 51 | 70 | 13 |

DINOv2 기본 설정 `long_side=700`, `photo_aug=0`, `seed=42`를 유지한다.
임계값은 밝은 정상 보정 점수 최댓값 × 1.2이며, 검증 점수로 조절하지 않는다.
두 실험은 정상 학습의 조도 구성과 표본 수, 보정 집합이 함께 달라진다.
따라서 학습 표본 수를 통제한 순수 조도 효과 실험과는 구별한다.

새 모델은 검증 268장 전부를 평가한다. 기존 모델과 비교할 때는 **기존 검증 227장**만
사용한다: 밝은 정상 134장·불량 70장, 어두운 정상 10장·불량 13장.
이전 학습/보정에 쓰인 어두운 정상 41장은 새 모델의 추가 평가로만 해석한다.
이전 모델의 학습 이미지를 평가에 다시 넣어 일반화 성능처럼 보고하지 않는다.

원본 경로·라벨·파일 해시·RGB 해시를 실행 전후 비교한다. 불량 위치 마스크가 없어
평가는 이미지 단위로 수행한다. 같은 촬영 날짜가 학습과 검증에 걸쳐 있고,
어두운 데이터가 한 날짜에 몰려 있어 독립적인 조도 인과효과나 새 날짜 일반화를
확정하는 결과는 아니다.

## 결과

밝은 정상만으로 보정한 임계값은 **0.1738106310**이다. 이전 모델은 0.1734326005였다.
학습에는 약 68.5초, RGB 이미지를 사전 로딩한 추론의 중앙값은 약 34.4ms가 걸렸다.
파일 읽기·원본 해상도 지도 생성·저장 시간은 추론 시간에서 제외한다.
자동 회전 정합은 활성화되지 않았다.

| 새 모델 검증 조건 | 정상 오탐 | 정상 오탐률 | 불량 검출 | 불량 검출률 | 이미지 AUROC |
|---|---:|---:|---:|---:|---:|
| 밝음 | 1/134 | 0.75% | 69/70 | 98.57% | 0.99755 |
| 어두움 | 43/51 | 84.31% | 11/13 | 84.62% | 0.43439 |
| 전체 | 44/185 | 23.78% | 80/83 | 96.39% | 0.96698 |

기존 모델과 **동일한 어두운 검증 23장**으로 비교하면 다음과 같다.

| 학습·보정 구성 | 정상 오탐 | 불량 미검출 | 이미지 AUROC |
|---|---:|---:|---:|
| 기존: 어두운 정상 포함 | 0/10 | 0/13 | 1.00000 |
| 새 모델: 어두운 정상 제외 | 9/10 | 2/13 | 0.43846 |

어두운 정상의 점수가 크게 올라가며 불량 점수와 겹친다. 어두운 조건의 AUROC가
0.434이므로 이번 결과에서는 임계값 하나를 옮기는 것만으로 정상·불량을 잘 분리하기
어렵다. 검증 결과를 보고 임계값이나 라벨을 수정하지 않았다.
이 실험은 촬영 조건이 학습에 포함되지 않았을 때 발생하는 오탐의 실제 사례로
활용할 수 있다. 학습 수와 보정 집합도 바뀌었다는 조건을 함께 제시해야 한다.
