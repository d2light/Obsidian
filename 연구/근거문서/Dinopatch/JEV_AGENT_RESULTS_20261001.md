# JEV 역할 분담 검사 결과

후속 판정·설명 분리 실험: [JEV_EXPLANATION_RESULTS_20261001.md](file:///E:/DH/Sandbox/Dinopatch/docs/JEV_EXPLANATION_RESULTS_20261001.md). 기존 검출을 유지해31/32건 검출, 추가 조회 후 설명 근거35/36건 일치. 검출 성능 개선이 아니라 과도한 보류를 분리한 결과다.

NG 판정3건의 쉬운 시각 설명: http://127.0.0.1:8765/output/comparisons/jev_ng_evidence_20261001_101831/index.html

최종 NG와 물리적 결함 설명은 구분해야 한다. 외피 사례는 외관 점수0.469/기준0.305가 주 근거이며, 저장 지도는 화면 아래쪽 외피 틈 부근에 강하게 반응한다. 나머지2건은 색상 구성 점수가 주 근거이고, 동일 계산을 재현하면 파란 부품P1의 정상 참조 대비 색상 거리가 가장 크다. 이것만으로 JEV가 구리선 누락을 알아냈다고 말할 수 없다. 보고서의 위치는 사후 측정 재현이며 JEV가 직접 반환한 좌표가 아니다. 사람의 이미지 해석도 당시 에이전트 출력과 구분했다.

## 구현한 구조

요청 모델 `typesafe/jev-1.13`, 실제 응답 모델 `typesafe/jev-1.13-20260917`. 버전 자동 변경과 다른 모델 대체를 사용하지 않았다.

관찰·외관·구성 담당이 제한된 자기 근거를 각각 평가하고, 조정 담당이 추가 근거를 선택해 조회한다. 반증 담당은 근거 부족/충돌을 지적하고, 종합 담당이 판정과 주 근거를 선택한다. 마지막 코드 검증은 없는 근거를 인용한 NG나 근거 부족 상태의 OK를 보류로 바꾼다. JEV 제안과 코드 적용 후 판정을 모두 저장했다.

시각 도구는 기존 DINO 외관, SAM 색상 구성, 부품 확대, 정합·조도, Qwen3-VL-4B의 **저장된 결과를 조회**한다. 새로운 이미지에서 시각 도구까지 실시간 실행하는 완성 검사기는 아니다. 모든 JEV 역할이 동일 모델이므로 독립된 전문가들의 합의로 해석하지 않는다. LLM/VLM의 자유 대화·토론 대신 역할별 구조화된 판단과 명시적 도구 조회 루프를 구현했다.

## 동일36건의 결과

18개 원본(정상2·불량16)의 원본/복합 조건, 총36건. 표의 정상4건·불량32건은 독립된36개 제품이 아니다. 표본은 기존 로컬 VLM 개발 실험 전체와 같으며 성공 사례를 고른 것이 아니다. 새 독립 평가셋이 아니다.

| 구성 | 불량 검출 /32 | 불량 자동 OK /32 | 정상 오탐 /4 | 전체 보류 /36 |
|---|---:|---:|---:|---:|
| 기존 외관+색상 고정 규칙 |31|1|0|0|
| 단일 JEV + 모든 근거 |2|0|0|31|
| 역할 분담 + 선택 조회 |3|0|0|32|
| 역할 분담 + 모든 근거 |1|0|0|35|

**이번 구성은 기존 검출기보다 성능이 좋지 않았다.** 불량 자동 OK가0이라는 수치만 보면 안 된다. 대부분을 보류했으며 실제 불량 검출은 크게 줄었다.

선택 조회 구성은 부품 확대36회·정합 결과27회, VLM 조회0회를 선택했다. 모든 역할과 조회 결과·확률·원문 요청·응답을 보존했다. 더 많은 관찰을 제공한 전체 검사 구성이 오히려 더 많이 보류했다. 정보량 증가만으로 종합 판단이 좋아진다고 볼 수 없다.

## JEV 자체 출력과 최종 정책을 구분

- 선택 조회 JEV 제안은 REVIEW29·NG4·OK3건. 코드 정책 뒤 REVIEW32·NG3·OK1건이다.
- 단일 JEV 제안은 REVIEW25·NG8·OK3건. 최종 REVIEW31·NG2·OK3건이다.
- 전체 조회 JEV 제안은 REVIEW32·NG1·OK3건. 최종 REVIEW35·NG1·OK0건이다.
- 선택 확률0.65 기준은 사전에 정한 연구용 정책이며 실제 결함 확률로 보정되지 않았다. 보류가 많은 원인은 코드 기준뿐 아니라 JEV 자체의 보류 선택에도 있다.
- JEV가 고른 이유 코드가 판정과 모순될 수 있어 원래 코드를 남기고 표시용 이유는 검증된 판정/주 근거에서 생성했다. 설명이 JEV의 내부 사고 과정을 그대로 보여주는 것은 아니다.

## 실행과 검증

최종 실행 `output/comparisons/jev_agents_20261001_094931`:387개 논리 호출 중324개는 동일 요청의 저장 응답 재생,63개는 신규 호출. 실행 중 반올림 확률 검증 오류, 로그 폴더 생성 누락, 연결 종료와 HTTP520을 고쳤거나 실패 이력으로 보존했다. 네트워크 오류 후 새 실행에서 재개했으며 모델/개인정보 설정은 완화하지 않았다.

연결 시험과 실패·재개 실행 전체의 서로 다른 성공 응답425개에 기록된 비용 합계는 **0.020685714달러**다. 응답을 못 받은8건의 청구 여부는 알 수 없어 최종 청구액을 보장하지 않는다. 마지막 실행 status의0.003033492달러는 그 실행의 신규 요청분만 의미한다. 캐시 비용을 중복 청구한 것으로 집계하지 않았다.

- 새 JEV 테스트12개, 기존 reasoning 테스트41개 통과.
- 최종 산출물 manifest, 원본 예측 파일 해시,387개 요청의 입력 허용 목록을 확인했다.
- 정답·파일명·경로·합성변형 정답이 API 요청에 들어가지 않았고, 선택 조회의 종합 담당에게 미선택 도구의 결과가 전달되지 않았음을 확인했다.
- 공개 cable 관찰 텍스트/수치만 전송했다. 사용자 산업 이미지나 원본 이미지 파일은 보내지 않았다. 키와 인증 헤더는 기록하지 않았다.
