## 이번에 확인한 결론

**하나의 모델에 기법을 계속 붙이는 것보다, 외관·부품 구성·관찰 가능 여부를 분리하고 각 근거의 실제 기여를 검증하는 방향이 유효했다.** 정상 증강은 촬영 변화에 의한 오탐을 줄였고, SAM 부품의 색상 구성은 cable swap 검출을 보완했다. 정합·기하 관계·부품 확대·VLM을 추가한다고 항상 좋아지지는 않았다.

이 결과는 이미 관찰한 개발 평가셋의 실험이다. 인간과 같은 이해나 모든 상황의100% 검사를 구현했다는 뜻은 아니다. Waterseal은 이번 일괄 실험에서 다시 평가하지 않았다.

## Cable: 외관과 구성 근거를 함께 보기

- 정상 증강은 복합 조건 오탐46→2장으로 줄였지만, 원본 cable swap12장은 여전히 모두 놓쳤다.
- 이 cable 기준모델은 고정 시드의 무작위12,000패치 메모리를 사용한 연구 비교다. 공식 PatchCore 재현 결과와 동일시하지 않는다. 기준모델과 증강 모델의 메모리 예산은 같지만 원본 패치 선택까지 완전히 동일하지는 않다.
- 부품 색상 구성은 실제 swap 사례에 도움이 됐다. 다만 색상 집합이 같은 순수 위치 교환을 일반적으로 해결하는 방법은 아니다. 색상 구성 단독의 원본 swap12장 검출과 기하 관계의 효과를 구분해야 한다.
- 더 단순한 **정상 증강 + 전체 부품 색상 구성**을 다음 검증 후보로 남긴다. 원본 미검2장은 `missing_wire/000.png`, `missing_wire/007.png`이며 정상 오탐5장도 남는다.
- 부품 확대는000을 단독 검출했으나, 통합 임계값이 올라 최종 판정은 여전히 OK였다. 전체 미검도 늘어 채택하지 않는다. 정상 보정 표본45장은 동일했다.
- 보류는 성능 계산에서 삭제하지 않았다. 정합이나 분할 실패를 정상 또는 실제 부품 누락으로 단정하지 않는다.

## 자세 추정과 VLM은 어디까지 도움이 됐는가

SAM 색상 대응으로 양쪽 관찰이 성공한 회전56쌍의 평균 정합 일관성 오차는2.43px였다. 그러나 원본 전체150건 중71건, 복합 조건113건을 보류했다. 조건부 정합의 개선을 전체 검사 성능 개선으로 해석할 수 없다.

로컬 Qwen3-VL-4B는18개 원본(정상2·불량16)의 원본/복합 조건만 비교했다. 원본에서 이미지 전용은 불량8/16, 수치 근거 제공은12/16 검출했다. 복합 조건에서는 수치 근거 제공 시 불량8건 검출·1건 미검·전체7건 보류였다. 보이는 결함을 없다고 설명하는 사례도 남았다. VLM은 근거를 요약하거나 재확인하는 보조 후보이며 수치 판정을 덮어쓰지 않는다. 출력 박스는 정답 위치가 아닌 모델의 가설이다.

## 실제 검사 데이터

원본은 변경하지 않고 확보한 사본으로 시간 분 그룹과 정확한 RGB 중복을 묶어 분할했다. 같은 제품을 여러 번 찍었는지, 시간 분 경계가 실제 독립 세션인지는 아직 증명되지 않았다.

### IV 금속 링

- 정상 전용: FIT정상200, CAL정상100, 평가정상691·불량690. FIT/CAL시간 그룹의 불량300장은 이 실험에서 제외했다.
- 정상 메모리 기본 임계값(max CAL×1.2): 오탐0·미검688, AUROC0.8771. 임계값이 지나치게 보수적이었다.
- 동일 점수의 정상 q95: 오탐132·미검65. 평가를 보고 최선 규칙만 고른 결과가 아니라 고정한 여러 규칙을 함께 기록했다.
- 추가 감독 비교: 같은 FIT시간 그룹의 불량196장까지 사용해 고정 DINO 특징 위 선형 분류기를 학습했다. 정상 전용 모델과 학습 정보가 다르다. CAL그룹 불량104장은 사용하지 않았다.
- 선형 분류기 정상 q95: 오탐58·미검0. 기본 분류 경계logit0: 같은 평가셋과 네 합성 변화 모두 오탐0·미검0, AUROC1.0이었다.
- 회전 조건의 q95 오탐은690/691로 증가했다. **점수 순위가 완벽해도 부적절한 임계값은 실패할 수 있다.** logit0은 원본 결과 확인 뒤 기본 분류 규칙 대조군으로 추가했으며, 변형 점수를 보기 전에 고정했다. 평가셋의 간격에 맞춰 최적 임계값을 탐색하지 않았다.
- 이는1,381개 원본의 반복 변형6,905건에 대한 결과다. 새로운 제품·세션·실제 조명 노후화까지100%라는 뜻은 아니다. 특징 기여도 지도는 실제 결함 분할 마스크가 아니다.

### 볼트

카메라1 원해상도만 사용했다. FIT정상275, CAL정상152, 평가정상2,272·불량5장. 다른 카메라·해상도는 별도 보존했다.

기본 임계값에서 오탐17·검출1·미검4, AUROC0.9575였다. 정상 q95로 내리면 불량5/5를 검출하지만 정상372장을 오탐했다. 불량이5장뿐이므로 일반화나 안정적인 재현율을 주장할 수 없다.

## 다음 연구 구성

1. **관찰 단계:** 제품 존재, 분할 가능 여부, 자세·밝기 추정의 신뢰도를 기록한다. 관찰 실패는 재확인 상태다.
2. **외관 검사:** 정상 증강 DINO 메모리로 국소 표면 결함을 본다. 충분한 검수 NG가 있는 제품에는 간단한 지도 분류기를 별도 비교한다.
3. **구성 검사:** 부품 색상·개수·관계를 제품 규칙에 맞춰 별도 측정한다. SAM 분할 실패만으로 부품 누락을 선언하지 않는다.
4. **판정과 설명:** 실제 임계값 초과 근거, 지도, 정상 참조, 보류 사유를 함께 출력한다. VLM 설명은 검증할 보조 가설로 둔다.
5. **독립 검증:** 새로운 촬영 날짜/제품 단위로 분리한 데이터를 확보하고 모델·임계값을 고정한 뒤 평가한다. 허용 회전, 구성 규칙, 결함 영역 라벨을 먼저 명확히 한다.

학습된 GNN, VLM 자율 도구 선택, LoRA 튜닝, 제품 공통 완성 검사기는 이번 구현 범위에 포함되지 않는다. 실험 코드는 `tools/`에 분리했고 공개 `dinopatch` API는 변경하지 않았다. 유료 API 호출 없이 로컬 모델로 수행했다.
