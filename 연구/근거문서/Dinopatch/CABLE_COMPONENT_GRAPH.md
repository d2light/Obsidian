# 부품 그래프 + 회전을 허용한 CNN 검사 시제품

실행: `output/experiments/DinoPatch_20260929_151335_cable_component_graph_orbit`.

## 원본 이미지 평가 결과

| 분기 | 정상 OK / NG / REVIEW (58장) | 불량 OK / NG / REVIEW (92장) | swap OK / NG / REVIEW (12장) |
|---|---|---|---|
| 회전 허용 CNN | 57 / 1 / 0 | 5 / 87 / 0 | 4 / 8 / 0 |
| 부품 그래프 | 40 / 1 / 17 | 30 / 7 / 55 | 0 / 1 / 11 |
| 결합, 분할 실패 보류 우선 | 40 / 1 / 17 | 1 / 36 / 55 | 0 / 1 / 11 |

fit 그래프는 179장 중 107장을 사용할 수 있었고 72장은 분할 품질 조건을 통과하지 못했다. test 자동 판정 coverage는 graph/hybrid 모두 78/150=52%다. swap 11장을 보류한 것을 불량 검출로 계산하면 안 된다. 결합 모델의 조건부 AUROC 98.62%는 **분할 성공 78장만**의 결과이므로 전체 성능 개선으로 해석하지 않는다. CNN 단독은 전체 150장의 AUROC 99.42%, 정확도96%다.

이번 시제품에서는 분할 실패 시 CNN이 NG 근거를 보이더라도 REVIEW를 우선하는 보수적 정책을 사용했다. 그 때문에 결합 정책이 CNN 단독보다 자동 판정 범위를 크게 줄였다. 이는 고정한 정책의 결과이며 결과를 보고 정책을 바꾸어 성능 향상처럼 제시하지 않는다.

현재 병목은 안정적인 부품 분리와 색상별 개수 표현이다. 다음 단계의 후보는 **색상과 독립적으로 부품 인스턴스를 먼저 나눈 뒤 색상을 분류**하여, 특정 색상을 강제로 하나씩 찾지 않고 중복·누락을 표현하는 방식이다. 아직 구현·검증된 개선이 아니다.

회전 검증 완료: 정상 58장의 0/90/180/270도 각각에서 CNN 단독은 OK57/NG1, 결합 정책은 OK40/NG1/REVIEW17로 유지됐다. 232회 실제 추론의 점수와 판정 불변성, 저장 모델 점수·마스크·이상맵 재현 4건, 원본 무변경과 아티팩트 검증을 통과했다. 분할과 그래프 마스크 일치 및 CSV/JSON 일치도 검증했다.

목적은 정상 회전을 허용하면서 부품 구성 이상을 검사할 수 있는지 확인하는 것이다. 일반적인 추론 모델이나 GNN 학습은 아니다. 기존 제품 모델을 변경하지 않는다.

## 방법과 감독 정보

- 기존 cable 분할을 유지한다: 정상 fit 179장, 정상 calibration 45장, test 정상58/불량92장.
- 에이전트가 직접 확인한 **fit 정상 000/003/007**에 노란색·파란색·갈색 피복의 고리 형태 예시 영역을 지정했다. 금속 중심과 바깥 영역은 기타 예시다. 사람의 검토를 받은 정밀 분할 정답이 아니며, 완전 비지도 비교도 아니다.
- 고정 DINOv2-registers-base 700 입력 특징과 정규화 Lab 색상 거리로 각 피복을 찾는다. 원본과 90/180/270도 뷰의 예시 특징을 쓰고, 추론에서도 네 회전의 의미별 거리를 원래 좌표로 돌려 평균한다.
- 3x3 closing 후 겹치는 후보는 **의미 거리로 하나의 부품에 배정한 다음** 연결 영역·면적·중심을 계산한다. 표시된 마스크와 그래프에 사용된 마스크는 동일하다.
- 각 색상에서 가장 큰 연결 영역을 사용한다. 면적 20~500/2500, 해당 색상 픽셀의 60% 이상, 중심 사이 거리 4패치 이상이 품질 조건이다. 실패하면 REVIEW이며 정상으로 처리하지 않는다. 이 조건을 통과했다고 의미 분할 정확도가 보장되는 것은 아니다.
- 그래프는 색상으로 구분된 세 부품의 상대 거리 3개, 면적 비율 3개, 부호 있는 방향 관계 1개로 구성한다. fit에서 분할이 유효한 정상 그래프를 저장하고, MAD 기반 척도(하한0.03)로 나눈 최대 성분 차이가 가장 작은 정상 그래프와 비교한다.
- CNN은 앞서 학습한 공식 PatchCore의 동일 정상 fit 메모리를 재사용한다. 전체 영상의 네 회전을 각각 검사하고 가장 낮은 이미지 점수를 선택한다. 개별 부품을 따로 회전·이동·재배열하지 않는다.
- 두 분기 임계값은 각각 정상 calibration 점수 q95(higher)다. 관계 임계값은 분할 가능한 calibration에서 계산하며 제외된 수를 따로 공개한다. hybrid는 두 정규화 점수의 최댓값으로 NG를 판단한다. 분할 실패는 CNN 점수와 무관하게 REVIEW를 우선한다.

## 해석과 한계

회전 불변성은 네 회전의 집합을 사용해서 **명시적으로 설계한 것**이다. 모델이 임의 회전 규칙을 스스로 배웠다는 증거가 아니다. 전체 장면이 디지털 회전하며 실제 물체만 회전한 촬영이나 작은 각도는 평가하지 않았다.

현재 구현은 의미 색상마다 가장 큰 한 영역을 취한다. 일반적인 인스턴스 분할이나 색상별 부품 개수 추정기는 아니다. 평가 중 원본을 확대해서 확인한 `cable_swap/000`은 갈색 대신 파란색이 들어가 파란색이 둘인 사례이며, `001`은 노란색 대신 파란색이 들어간 사례다. 따라서 이 폴더를 단순한 위치 순서 교환으로 설명한 이전 가정은 불충분했다. 색상별 개수·누락·대체가 필요하며 현재 고정 시제품이 해당 사례를 REVIEW로 보낼 수 있다. 이 발견 후 테스트 결과에 맞춰 구성을 바꾸지는 않았다.

분할 실패는 모든 표본 수에 포함한다. CNN 단독은 전 표본 AUROC, graph/hybrid는 점수가 있는 표본의 조건부 AUROC와 coverage를 함께 기록한다. `correct_over_all`은 REVIEW를 정답으로 계산하지 않는다. 결함 위치 맵은 CNN 이상맵과 관계에 관여한 부품의 귀속 표시를 합친 것이며 픽셀 단위 결함 확률이 아니다. 따라서 픽셀 AUROC를 주장하지 않는다.

## 검증

`ExperimentArtifacts` 공통 생성기와 `component_graph_probe` 종류의 3단계 판정 검증기를 사용한다. 원본/학습 해시, CSV와 JSON 일치, 각 분류 목록, 면적·중심과 마스크 일치, 그래프 거리 재계산, 임계값, 메트릭과 회전 요약, HTML 링크를 검증한다. 저장 모델 재로딩 후 정상/불량의 점수·마스크·CNN 맵을 대조하고, 정상 58×4회전은 실제 재추론으로 점수·판정 불변성을 확인한다.

```powershell
.venv/Scripts/python.exe -m unittest tests.test_component_graph tests.test_benchmark
.venv/Scripts/python.exe -m tools.probe_component_graph --pilot
.venv/Scripts/python.exe -m tools.probe_component_graph
```

`151100` 실행은 closing 영역 중첩으로 계산 마스크와 표시 마스크가 달라지는 문제가 발견되어 중단·무효화했다. `151335`는 이를 수정한 새 실행이다. 첫 fit 12장으로만 피복 예시와 분할 처리를 조정했으며, 이후 정상 fit 전체에서 실패가 상당수 존재했다. 이 시제품은 실사용 모델이나 최종 성능 결과가 아니다.
