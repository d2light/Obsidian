# Waterseal 이상 맵 점검과 전처리 비교

## 기존 모델 점검

밝은 정상 224장만 학습한 기존 모델을 다시 불러 보정·검증 353장 전체를 재추론했다.
기존 CSV 점수와 일치함을 확인한 후, 실제 패치 거리·채점 마스크·마스킹 전 거리맵을 저장했다.
검증 NG 83장(밝음 70, 어두움 13)의 전체 11페이지를 육안으로 점검했다.
픽셀 정답 마스크가 없으므로 위치 검출 정확도 수치는 주장하지 않는다.

밝은 NG의 전형적인 띠 끊김, 들뜸, 큰 변형에서는 결함 부근에 높은 반응이 보인다.
그러나 자동 배경 전환이 켜진 일부 영상에서는 실제 물체 영역 대부분이 제외되고,
하단 반사 영역이나 작은 조각만 남는다. NG 판정이 맞아도 결함 위치를 정확히
찾았다고 해석할 수 없다. 특히 어두운 NG에서는 이 현상이 뚜렷하다.

| 검증 그룹 | 이미지 수 | 자동 배경 전환 | 채점 패치 비율 중앙값 | 전체 패치의 5% 미만만 남은 영상 |
|---|---:|---:|---:|---:|
| 밝은 정상 | 134 | 0 | 85.78% | 0 |
| 밝은 불량 | 70 | 8 | 86.27% | 5 |
| 어두운 정상 | 51 | 50 | 2.27% | 43 |
| 어두운 불량 | 13 | 13 | 1.14% | 13 |

이 비율은 **물체 마스크 정확도가 아니라 전체 패치 중 채점에 남은 비율**이다.
작게 남았다는 사실만으로 오류라고 판정하지 않으며, 원본 물체와 함께 확인했다.
밝은 미검출 `20250819_080309000_0000234794_T0000_01_CAM.jpg` 역시 작은 영역만
남는 사례다. 어두운 불량에서도 물체 대신 하단에만 반응하는 TP가 있어 판정과 위치를 구분해야 한다.

## 시각화 구성

각 모델의 보정·검증 이미지 **전부**에 대해 다음을 한 화면에 제공한다.

1. 원본 이미지
2. 이미지별 최댓값 기준 상대 색상 오버레이
3. 이미지 판정 임계값의 0~2배를 공통 범위로 쓰는 오버레이
4. 전처리 영상(인코더 리사이즈 전)
5. 실제 채점 패치 마스크: 흰색이 남은 영역
6. 배경 제거 전 패치 거리맵

상대 색상은 정상 이미지도 빨갛게 보일 수 있다. 고정 범위 역시 이미지 판정 임계값을
표시 단위로 빌린 것이며, 픽셀 결함 판정 기준이 아니다. 모델 간 임계값은 다를 수 있다.
ROI 모델의 패치 마스크는 크롭 내부 격자이며, 최종 맵은 원본 좌표의 ROI에 되돌려 넣는다.
크롭 밖의 0은 검사하지 않았다는 뜻이지 정상이라는 증거가 아니다.

추가로 전체 NG 연락 시트, 밝음/어두움·NG/FP/FN 필터, 점수 분포·혼동행렬·ROC,
마스크 잔존 비율과 점수의 관계, 마스킹 전후 최댓값 변화, 수치 CSV/NPZ를 저장한다.

## 비교 실험

기존 밝은 정상 224장 학습, 85장 임계 보정, 검증 268장을 그대로 사용한다.
어두운 이미지는 어떤 모델의 학습·보정에도 들어가지 않는다.

| 구성 | 목적 |
|---|---|
| 기존 auto_bg | 기준선 |
| full_none | 자동 배경 분리를 끈 효과 |
| roi_none | 명시적 ROI 크롭의 효과 |
| roi_gain | ROI 안 P90 밝기를 160에 맞춤, 배율 0.25~4 |
| roi_clahe | ROI의 LAB L 채널 CLAHE, clipLimit 2, 8×8 타일 |

`full_none`은 마스크만 제거한 동일 뱅크 실험이 아니다. auto_bg의 물체·배경 분리 뱅크를
단일 정상 뱅크로 바꾸므로, 배경 처리 모듈 전체를 끈 대조군으로 해석한다.

ROI는 **학습 정상 224장만**으로 산출했다. 평균 영상의 밝은 띠 후보에 31×5 Closing과
최대 연결 영역을 적용하고, 학습 영상 각각의 띠 위치 범위에 원본 높이 10% 여유를 준다.
결과 ROI는 `(x0,y0,x1,y1)=(0,738,2544,1257)`이다. 형태학의 역할은 학습 영상에서
ROI 후보를 정리하는 것이다. 형태학 자체의 독립 기여를 측정한 실험은 아니다.
불량 원본을 메우거나 이상 맵의 작은 반응을 삭제하지 않는다.

위치가 크게 달라진 NG가 ROI 밖에 놓일 수 있다. 해당 이미지를 평가에서 제외하지 않으며,
고정 ROI의 한계로 기록한다. 모든 전처리는 학습·보정·예측에 동일 적용하고 모델을 새로 만든다.
임계값은 각 모델의 같은 밝은 정상 보정 85장 점수 최댓값 × 1.2로 정하며, NG 결과로 조정하지 않는다.

원본 `D:\datasets\waterseal`은 읽기 전용으로 취급한다. 모델마다 원본 평가 사본,
원본 해상도 수치 맵, 실제 패치 맵, 체크포인트, 보고서를 새 실험 폴더에 보존한다.
현재 검증 데이터는 이미 살펴본 개발 검증이며 독립 최종 성능은 새 촬영 데이터로 확인해야 한다.

## 실험 결과

모든 구성은 동일한 밝은 정상 학습 224장·보정 85장과 검증 268장을 사용했다.
밝은 검증은 정상 134장·불량 70장, 어두운 검증은 정상 51장·불량 13장이다.

| 구성 | 밝은 정상 오탐 | 밝은 불량 미검출 | 어두운 정상 오탐 | 어두운 불량 미검출 | 어두운 조건 AUROC |
|---|---:|---:|---:|---:|---:|
| 기존 auto_bg | 1/134 | 1/70 | 43/51 | 2/13 | 0.43439 |
| 전체 영상, 배경 분리 없음 | 1/134 | 0/70 | 51/51 | 0/13 | 0.73303 |
| ROI | 0/134 | 1/70 | 51/51 | 0/13 | 0.64103 |
| ROI + 밝기 정규화 | 0/134 | 1/70 | 51/51 | 0/13 | 0.77828 |
| ROI + CLAHE | 0/134 | 1/70 | 51/51 | 0/13 | 0.71795 |

배경 처리 모듈을 끄면 기존 미검출 3장은 잡히지만 정상 오탐이 44장에서 52장으로 늘었다.
ROI 세 구성에서는 모두 `20250818_222058977_0000093351_T0000_01_CAM.jpg`를 놓쳤다.
보정 임계값은 full_none 0.17149724, roi_none 0.20372080, roi_gain 0.20689375,
roi_clahe 0.24463905이다. 검증 NG를 사용해 임계값을 재조정하지 않았다.

이번 고정 설정들로는 어두운 정상 오탐 문제를 해결하지 못했다. 밝기 정규화는
어두운 조건의 점수 순위 구분을 일부 개선했지만, 정상 보정으로 정한 임계값에서는
오탐이 줄지 않았다. 따라서 새 구성을 기존 기본값으로 교체하지 않는다.
후속 연구에서는 조도 변화에 대한 특징 강건성과 자동 물체 마스크의 품질 판정을
각각 검증해야 한다. 검출률이 높다는 이유로 맵의 위치 정확도를 주장하지 않는다.

## 재사용

공통 실험 실행기의 `inspection=True`가 기본값이므로, 이후 기본 auto_bg/none 실험도
전체 검사 갤러리를 자동으로 생성한다. 기존 실험은 다음 명령으로 보강할 수 있다.

```powershell
python -m tools.visualize_run --run <실험폴더> --replay
python tools/validate_experiment_artifacts.py --run <실험폴더> --record
```

ROI와 조도 보정은 `Config`에 저장되어 모델 로드 시 동일하게 적용된다.

```python
cfg = Config(align=False, mask="none", roi_box=(0, 738, 2544, 1257), illumination="clahe")
det = AnomalyDetector(cfg).fit(train_paths)
det.calibrate(calibration_paths)
det.save("detector.pt")
```

위 ROI 좌표는 이번 카메라·해상도·학습 데이터 전용이며 다른 제품에 그대로 쓰지 않는다.
