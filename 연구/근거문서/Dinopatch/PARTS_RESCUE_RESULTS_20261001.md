# 정확도 우선 연구 — 기존 기준을 유지한 부품 확대 추가

사용자 요청: 정확도 개선을 우선하고 속도 최적화는 검증된 구성이 나온 후 진행한다. 원본 데이터와 배포용 기본 구성은 변경하지 않는다.

보고서: http://127.0.0.1:8765/output/comparisons/parts_rescue_20261001_155115/index.html

## 고정한 가설

이전 부품 확대 결합은 통합 임계값 상승 때문에 기존 불량도 놓쳤다. 이번에는 기존 DINO+SAM 색상 결합 판정과 기존 부품 확대의 정상 CAL 기준을 모두 유지했다. 기존 NG는 보존하고, 부품 확대 점수가 자체 기준0.39942121505737305를 넘는 경우만 NG를 추가한다. 대조군은 추가 양성을 NG 대신 REVIEW로 기록한다. 기존 REVIEW를 부품 음성이나 관찰 실패로 OK로 바꾸지 않는다.

부품 관찰이 실패하면 원래 검사 범위의 판정을 유지한다. 따라서 원본150장 중 부품 확대 관찰 불가60장을 검사 성공으로 주장하지 않는다. 구성 요소 결합 시 정상 오탐이 늘 수 있으며 정상 보정셋45장을 재사용하므로 독립적인 오탐 보장이 아니다.

## 결과

같은 원본150장(정상58·불량92)의 원본·합성4조건, 총750관측을 저장된 결과로 재생했다. 새 학습·JEV 호출·새 데이터 평가는 아니다. 프로토콜을 평가 결과 로딩 전에 기록했지만 이미 알려진 개발 오류에서 세운 가설이므로 독립 검증으로 취급하지 않는다.

|---|---:|---:|---:|---:|
| 원본 |5→5|2→1|90→91|3→3|
| 어두움 |3→3|2→1|89→90|4→4|
| 회전 |5→5|3→1|87→89|8→8|
| 이동 |6→6|3→2|89→90|4→4|
| 복합 |5→5|2→1|89→90|4→4|

원본 자동 정답/전체 비율93.33%→94.00%(보류 분모 포함), 불량 검출90/92→91/92(98.91%). 새로 검출한 원본은 `missing_wire/000.png`, 부품 확대 점수0.435772717. 기존 미탐 `missing_wire/007.png`는 남는다. 정상 오탐5건과 보류3건도 해결되지 않았다.

REVIEW 대조군은 원본 검출90건 유지, 미탐1건, 보류4건이다. 미탐 감소를 검출 증가로 잘못 해석하지 않는다. 기존 통합 재보정 구성은 원본 오탐4·미탐7·검출85·보류3이었다.

이 실험은 별도 시각 분기를 더해 예산이 증가한다. 속도 측정을 하지 않았고 정확도 우선 요청에 따라 속도 최적화는 수행하지 않았다. 공식 PatchCore 원본 정확도96%를 넘어선 결과는 아니다.

## 다음 검증

추가 부품 양성 경로는 후보로 보존한다. 남은 미탐에서는 전체 부품 대표색과 DINO 패치가 놓치는 금속 중심의 재질 면적·결손 관측을 검토한다. 정상 오탐5건은 SAM 영역 혼입, 금속/피복 혼합, 조명 색 변화 등 실제 원인을 영상으로 확인한 뒤 가설을 정한다. 아직 원인을 확정하지 않는다. 동일 개발 영상에서 규칙을 반복 선택한 뒤 독립 평가 성능처럼 발표하지 않는다.

구현: `tools/experiment_parts_rescue.py`. 전체116테스트 통과. 산출물 해시와 입력 해시를 검증하며 시각화에는 판정이 달라진23관측의 외관·SAM·확대 카드69개를 제공한다. 실행: `.venv\Scripts\python.exe -m tools.experiment_parts_rescue`.
