# 연구 방향 재정리

작성일: 2026-09-30  
상태: 현재 논의 내용을 보존한 연구 방향 문서. 후속 실험 결과에 따라 수정한다.

## 1. 연구 목표와 제목

**제안 제목: 부품 영역 분할과 자세 정합을 이용한 산업용 부품 이상 탐지의 강건성 개선**

연구의 중심은 촬영 조건이 달라져도 같은 부위를 비교하여, 정상 오탐을 줄이면서 실제 결함 검출을 유지하는 것이다. 여러 모델을 연결하는 것 자체가 아니라 각 단계가 해결하는 문제와 개선 효과를 입증한다.

핵심 연구 질문:

> 정상 기준과 검사 영상의 동일 부위를 대응시켜 비교하면, 위치·회전 변화로 발생하는 오탐을 줄이면서 실제 결함 검출 성능을 유지할 수 있는가?

중간발표까지는 **위치·회전 변화와 정합**을 중심으로 검증한다. 조도 변화는 후속 확장으로 분리한다. 모든 환경에서 100% 성능을 보장하는 것을 연구 주장으로 삼지 않는다. 관찰이나 정합이 불확실한 경우를 구분할 수 있는 검사 구조를 지향한다.

## 2. 교수님 피드백과 주간보고서의 반영

1회차 주간보고서의 기간은 2026.09.18.~2026.09.30.이며, 연구 내용 구체화·데이터 수집 및 라벨링, 교수님 피드백과 향후 비교 실험 계획을 담았다.

| 피드백 | 연구에 반영할 사항 |
|---|---|
| 각 단계의 역할과 기여를 명확히 제시 | 동일 기준모델에서 영역 제한·정합·조도 처리를 단계별 비교 |
| 오탐 감소와 결함 검출을 함께 평가 | 정상 FPR, 불량 Recall, 불량의 OK 통과율, 보류율을 함께 보고 |
| 정합 실패를 정상으로 처리하지 않음 | 실패·모호성을 판정 보류로 구분하고 전체 평가에 포함 |
| 데이터와 평가 범위를 구체화 | 대표 품목과 조건·변화 강도를 먼저 정하고 범위를 점진적으로 확대 |
| 중간발표에 최종 성능이 필수는 아님 | 실제 문제 사례, 기준모델 결과, 비교 실험 설계, 이후 계획을 제시 |

기존 주간보고서의 방향은 유지하되, 조도·위치·배경·다양한 품목을 한 번에 해결하는 범위에서 위치·회전 대응을 먼저 검증하는 범위로 좁힌다.

## 3. 지금까지 확인한 내용과 해석 범위

| 관찰 및 실험 | 연구에 주는 근거 | 해석 제한 |
|---|---|---|
| 패치 기반 검사에서 cable의 일부 구성 이상을 놓침 | 부위 위치와 대응 관계를 고려할 필요 | 백본과 설정이 다른 결과를 그대로 공정한 모델 비교로 해석하지 않음 |
| 전체 회전 탐색으로 회전 정상의 오탐 감소 | 자세 대응의 효과를 검증할 근거 | 회전한 불량 검출 및 임의 자세의 전체 성능은 별도 검증 필요 |
| 단순 원·타원 방식의 부품 후보 검출 실패 | 학습된 분할 모델을 후보로 선택 | 색상과 독립적인 부품 구분이라는 전체 구조의 실패를 의미하지 않음 |
| 정상 FIT 3장의 박스 프롬프트 SAM 분할 | 내부 케이블 외곽을 부품 단위로 표현할 가능성 | 수동 프롬프트이며 자동 분할·미관측 일반화 성능이 아님 |
| 금속을 포함한 단면 마스크 구성 | 피복과 금속을 합친 부품 전체를 검사 단위로 사용 | 마스크가 제품의 실제 정답 경계임을 보장하지 않음 |
| 정렬용 마스크 보정과 전체 자세 대응 구현 | 원본 검사 근거 보존 및 기하학 처리 가능성 | 불량 검출 개선이나 자동 대응 성능을 입증한 것은 아님 |

### 최근 SAM 실험의 구체적 상태

- 모델: SAM 2.1 Hiera Small. 정상 FIT 000/003/007에 에이전트가 점·박스를 지정했다.
- 부품 전체를 대상으로 하며 금속 중심을 반드시 제외하지 않는다.
- 부품별 가장 큰 연결 영역 유지와 내부 구멍 채우기로 단면 마스크를 만들었다.
- 정렬용으로 opening 커널 5/11/21을 비교하고 11을 기본으로 사용했다. 기본 처리에서 제거된 646픽셀은 모두 검사 영역에 보존됐다.
- 정상 003과 007의 기준 마스크 겹침은 전체 정렬 전후 각각 0.7793→0.8645, 0.6400→0.8751이었다. 보정 후 수치는 유효 영상 영역 기준이다.
- 위 겹침은 정상 기준과 예측 마스크 사이의 기하학 지표이며 정답 분할 IoU나 이상 탐지 성능이 아니다.
- 마스크 보정 자체가 정렬 잔차를 항상 개선하지 않았다. 효과가 확인된 기여로 확정하지 않는다.
- 합성 회전 검사는 저장 마스크를 함께 변환한 좌표 계산 검증이다. 회전 영상에 SAM을 다시 실행한 결과가 아니다.
- 자동 부품 대응, 조도 대응, 실제 NG 검출 성능은 이 SAM 시제품에서 아직 평가하지 않았다.

## 4. 제안 구조와 설계 원칙

```text
정상 기준 영상 + 검사 영상
             ↓
        검사 부품 영역 추출
             ↓
     전체 위치·회전·크기 정합
             ↓
       대응 부위의 특징 비교
             ↓
       OK / NG / 판정 보류
          + 이상 위치와 근거
```

### 정렬용 마스크와 검사용 영역 분리

정렬을 위해 작은 돌출부와 불안정한 윤곽을 완화할 수 있다. 그러나 보정으로 제거된 영역을 검사에서 삭제하지 않는다. 원본 영상, 원래 SAM 마스크, 보정 마스크, 변경 영역을 함께 보존한다.

현재 시제품의 검사 영역은 원래 SAM 마스크와 단면 전체 마스크의 합집합에 주변 여유를 준 영역이다. 이 영역이 실제 모든 결함을 포함하는지는 추가 평가가 필요하다.

### 전체 물체의 자세만 보정

전체 이동·회전·균일 배율을 허용한다. 내부 부품을 각각 이동하거나 재배열하여 불량 구성을 정상처럼 만들지 않는다. 반사나 비선형 변형으로 실제 이상을 지우지 않도록 한다.

정합은 구조 대응을 기준으로 수행하며, 가장 낮은 이상 점수만을 목표로 자세를 선택하는 방식은 결함을 정상으로 설명할 위험을 별도로 평가해야 한다.

### 실패와 결함을 구분

정합·관찰·대응이 불확실하면 판정 보류 대상으로 남긴다. 이미 다른 검사 분기에서 확인한 NG 근거를 정합 실패 때문에 삭제하지 않는다. 실패 사례를 전체 평가에서 제외하지 않는다.

### 검사 범위와 분할 범위 일치

cable 내부 세 부품을 분할하는 것은 구성 검사에 활용할 수 있지만 외피 손상까지 검사하는 전체 cable 이상 탐지를 그대로 대체하지 못한다. 외피가 검사 대상이면 검사 영역에 포함해야 한다. 배경 제외 범위는 제품별 검사 요구에 맞춰 정한다.

## 5. 검증할 핵심 가설

**가설 A:** 부품 영역과 전체 자세를 맞춘 비교는 위치·회전 변화에 따른 정상 오탐을 줄인다.

**가설 B:** 정렬용 마스크를 보정하면서 원본 경계 정보를 검사에 보존하면, 보정 과정에서 실제 결함을 놓치는 위험을 줄일 수 있다.

현재는 검증할 가설이다. 결과가 나온 후 효과가 확인된 부분만 최종 기여로 정리한다. SAM·DINO·PatchCore를 함께 사용했다는 사실만으로 기여를 주장하지 않는다.

## 6. 비교 실험 설계

각 처리 단계의 효과를 볼 때 이상 탐지 백본, 학습 데이터, 점수 계산 방식은 고정한다. 임계값 산출 규칙과 검증 데이터도 동일하게 유지하고, 필요한 모델별 임계값은 정상 calibration에서만 정한다.

| 실험 | 구성 | 확인할 효과 |
|---|---|---|
| A | 기준모델 | 기본 오탐·미검출 |
| B | 기준모델 + 검사 영역 제한 | 배경 영향 감소 여부 |
| C | 기준모델 + 전체 정합 | 자세 변화 보정 효과 |
| D | 기준모델 + 영역 제한 + 정합 | 두 단계의 결합 효과 |

유효한 구성에서 정렬 마스크 보정 유무와 검사 경계 보존 유무를 추가 비교한다. 조도 처리는 이후 별도 비교 항목으로 추가한다.

기존 공식 PatchCore를 우선 기준으로 활용하고, DINO 기반 모델도 같은 평가 절차로 비교한다. 서로 다른 정합·전처리 조건을 적용한 결과로 백본 자체의 우열을 단정하지 않는다.

## 7. 데이터와 평가 범위

| 데이터 | 역할 |
|---|---|
| MVTec cable | 부품 분할·정합·구성 변화의 방법 개발과 실패 분석 |
| Waterseal | 현장 검증. 찢어짐·절삭면 불균일 등 검사 항목을 명확히 정의 |
| VisA 및 다른 품목 | 대표 품목에서 효과 확인 후 확장 |

- 원본 데이터는 변경하지 않는다.
- 파일/디코딩 이미지 중복뿐 아니라 동일 제품의 연속 촬영이 학습과 평가에 섞이는지 점검한다.
- Waterseal은 확보 가능한 제품·촬영 배치·날짜 정보를 이용하여 그룹 단위 분리를 우선 검토한다.
- 정상 학습, 정상 임계값 검증, 최종 평가의 역할을 분리한다. 평가 결과를 보고 임계값을 맞추지 않는다.
- 기존 cable 테스트셋은 여러 번 관찰한 개발 평가 데이터다. 최종 미관측 일반화 성능으로 주장하지 않는다.
- 먼저 회전과 이동을 각각 평가하고, 이후 복합 변화와 조도를 추가한다. 각 실험의 변화 강도는 실행 전에 고정하고 기록한다.
- 디지털 합성 변형과 실제 촬영 조건 변화는 별도로 보고한다. 합성 라벨과 원본 라벨을 구분한다.
- 정합 실패와 보류 사례를 제외하지 않는다.

## 8. 평가 지표

| 항목 | 의미 |
|---|---|
| 정상 FPR | 전체 정상 중 NG로 판정한 비율 |
| 불량 Recall | 전체 실제 불량 중 NG로 판정한 비율 |
| 불량 OK 통과율 | 전체 실제 불량 중 OK로 판정한 비율 |
| 정상/불량별 보류율 | 각 실제 라벨에서 REVIEW로 남긴 비율 |
| 자동 판정 비율 | 전체 표본 중 OK 또는 NG로 판정한 비율 |

보류된 불량을 검출 성공으로 계산하거나 전체 분모에서 제외하지 않는다. 조건부 성능을 제시할 때는 자동 판정 비율과 전체 표본 기준 결과를 함께 표시한다. 이미지 수준 판정과 결함 위치 평가를 구분하며, 위치 정답이 없는 데이터에서 픽셀 정확도를 만들지 않는다.

## 9. 중간발표 구성

1. **문제 정의:** 위치·회전·조도 변화로 정상 오탐이 발생하는 실제 사례.
2. **기준모델 결과:** 정상/불량의 원본과 이상맵, 오탐·미검출 사례.
3. **제안 방법:** 검사 영역 추출 → 전체 정합 → 대응 부위 비교 도식. 정렬용/검사용 마스크 분리 표시.
4. **현재 확인 결과:** SAM 수동 프롬프트 분할과 정합 가능성, 실패·한계. 실제 불량 검출 개선과 구분.
5. **비교 실험 설계:** 단계별 ablation과 FPR·Recall·보류율 평가 계획.
6. **향후 계획:** 자동 대응과 실제 정상·불량 평가, 이후 현장 데이터·조도 조건 확장.

발표용 연구 방향 문장:

> 본 연구는 촬영 조건 변화로 발생하는 산업용 부품 이상 탐지의 오탐을 줄이는 것을 목표로 한다. 우선 위치·회전 변화에 집중하여 부품 영역 분할과 전체 자세 정합의 효과를 단계별로 비교한다. 정합을 위한 마스크 보정 과정에서도 원본 경계 정보를 검사에 보존하며, 정상 오탐률·결함 검출률·판정 보류율을 함께 평가한다. 대표 공개 데이터에서 방법을 검증한 뒤 현장 워터씰 데이터와 조도 변화 조건으로 평가 범위를 확대한다.

## 10. 다음 작업 우선순위

1. 검사 대상 범위를 확정한다. 내부 부품, 외피, 절삭면 등 필수 검사 부위를 빠뜨리지 않도록 한다.
2. 자동으로 부품 위치를 찾아 SAM에 전달하는 과정을 검증한다. 수동 프롬프트 결과와 자동 파이프라인 결과를 구분한다.
3. 자동 부품 대응의 오류·모호성 및 정합 실패 기준을 정한다. 색상 교체를 정상처럼 재배치하지 않는지 확인한다.
4. 동일 기준모델로 실제 정상·불량 영상에서 정합 전후 FPR·Recall·보류율을 비교한다.
5. 효과가 확인된 구성에 대해 현장 Waterseal 및 조도 변화 평가로 확장한다.

이 문서는 방향과 우선순위를 정리한 것이다. 아직 수행하지 않은 단계가 구현·검증 완료된 것으로 해석되지 않도록 한다.
