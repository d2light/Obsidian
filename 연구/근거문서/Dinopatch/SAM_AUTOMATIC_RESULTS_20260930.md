# SAM 자동 부품 분할·회전 실험

정상 FIT 이미지에서 자동 부품 추출과 자세 복원이 가능한지 확인했다. **불량 검출 정확도 실험은 아니다.**

| 실험 | 결과 |
|---|---|
| 정상 FIT 전체 179장 자동 SAM | 174장에서 내부 부품 후보 3개, 5장에서 2개 |
| 정상 FIT 12장 × 실제 RGB 15°/90° 회전 | 24건 중 22건에서 후보 3개, 2건에서 2개 |
| 후보 3개인 회전 22건 | 원본 자동 마스크의 알려진 회전과 평균 IoU 일관성 0.9842 |
| 선택한 자세의 역변환 오차 | 30px를 초과한 사례 0건; 30px는 진단용 기준이며 운영 임계값이 아님 |
| 입력 잘림 감사 | 회전 24건의 내부 부품 픽셀 중심이 영상 밖으로 잘린 사례 0건 |

SAM2.1 Hiera Small에 32×32 격자 프롬프트를 자동 생성했다. 정상 3장의 기존 수동 SAM 결과에서 얻은 크기 범위와 형태 규칙으로 후보를 선택했다. 따라서 매 이미지의 수동 클릭은 없지만 정상 기준에서 얻은 크기 사전정보는 사용했다. 후보 수를 강제로 3개로 맞추지 않았다.

회전 실험은 RGB 자체를 돌린 후 SAM을 다시 실행했다. 자세는 세 중심의 가능한 대응 6개를 비교하는 단일 유사 변환으로 추정했다. 색상이나 알려진 회전값을 정합에 제공하지 않았으며 알려진 회전은 사후 오차 측정에만 사용했다.

010과 011 이미지의 15° 회전에서 부품 하나를 놓쳤다. 후보가 부족한 경우 자세를 생성하지 않았다. 정상으로 간주하면 안 되며 재확인 대상으로 처리해야 한다. 검은 패딩은 유효 관측 영역이 아니다. 입력·자세별 유효 영역을 별도 감사 결과에 저장했다.

174/179는 정확도가 아니라 후보 수가 기대와 맞은 비율이다. 정답 분할 마스크가 없고, 외피는 현재 선택 대상에서 빠져 있다. 회전 일관성도 정답 IoU가 아니다. 아직 전체 cable NG 판정이나 Waterseal·볼트로의 일반화를 주장할 수 없다.

다음 단계는 누락 사례에서 자동 마스크 생성과 후보 선택 중 어느 단계가 원인인지 분리하고, 외피를 포함한 검사 영역을 마련하는 것이다. 그 뒤 고정된 학습·검증 분할로 기본 패치 모델과 정합 추가 모델의 오탐·미검·판정 보류를 함께 비교한다.
