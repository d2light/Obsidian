# Cable 장거리 관계 실험

이전 color+position 모델과 1패치 관계 모델을 기준으로, 관계 거리만 4/8/16패치로 늘린다. 물체 단위 그래프 또는 GNN이 아니라 패치 평균 Lab의 상하좌우 차이를 정상 메모리에 저장하는 실험이다.

- 이전과 동일한 MVTec cable 분할: 정상 fit 179장, 정상 calibration 45장, test 150장(정상 58/NG 92).
- 동일한 frozen DINOv2-registers-base, 입력 long side 700, 50x50 격자, 동일 coreset 30,000개와 선택 인덱스를 재사용한다.
- DINO + color(.25) + position(.5)에 relation(.25)을 더한다. 각 관계 벡터는 4방향 x Lab 3성분 = 12차원이며, 거리별 계수를 조정하지 않는다.
- 거리 1/4/8/16은 인코더 입력에서 14/56/112/224픽셀에 해당한다.
- 각 방향의 같은 정상 패치에 대한 거리 합을 최소화한다. 관계마다 다른 정상 참조를 고르지 않는다.
- 경계 밖 연결은 0이며 wrap하지 않는다. 방향 슬롯 수는 동일하지만 유효 방향 연결은 각각 9800/9200/8400/6800개이다. 거리 효과와 경계 처리 효과가 완전히 분리된 것은 아니다.
- 임계값은 정상 calibration의 95% 분위수(higher). 테스트로 계수나 임계값을 선택하지 않는다.
- 이전 테스트의 실패를 관찰한 뒤 설계한 후속 실험이므로 이 테스트는 탐색용 개발 평가이다. 별도 최종 검증으로 취급하지 않는다.

실행:

```powershell
.venv/Scripts/python.exe -m unittest tests.test_cable_relations tests.test_benchmark
.venv/Scripts/python.exe -m tools.probe_cable_longrange
```

결과 폴더: `output/comparisons/cable_longrange_20260929_133743`.

`no_edges`는 기존 **DINO+색상+위치**이며 순수 DINO가 아니다. `near_1`은 기존 근거리 관계 구성이다. 이전 실험 결과와 원본 데이터는 변경하지 않는다. 새로운 세 모델의 체크포인트에는 `edge_distance`가 저장되어 로드시 같은 관계 거리를 재현한다.

비교 HTML에는 150장 전체 이상 맵과 실제 정상 참조 패치 확대가 포함된다. 정답 윤곽은 초록색이며, 지도 빨강은 각 이미지 임계값의 2배를 뜻한다. 픽셀별 결함 확률이나 결함 판정 임계값이 아니다. 손실함수/역전파 최적화는 사용하지 않는다.
