# 철환 연구 프로젝트 구분

`ai_solution`이라는 공통 코드 폴더명 대신 `JY-METALRING`을 고정 ID로 정했다. 철환 연구의 개요, 실험, 일지, 첨부를 프로젝트 폴더 안에서 관리한다.

[프로젝트 개요](../개요.md)와 [프로젝트 목록](../../../운영/프로젝트%20목록.md)을 만들고 기존 기록을 연결했다. 다른 세션의 미커밋 노트는 수정하거나 이동하지 않았다.

이번 작업은 기록 구조를 정리한 것이다. 새 모델 실험이나 성능 재평가는 수행하지 않았다. 다음 작업은 기존 실험 산출물을 대조하면서 철환 연구 흐름을 실험별 노트로 재구성하는 것이다.

## 신규 촬영 이미지 전수 예측

[신규 미라벨 예측 결과](../실험/2026-10-02_JY-METALRING_신규미라벨예측_115410.md)를 추가했다. 640×480 JPEG 7,193장을 GPU로 예측하고 불일치·경계 검토 이미지 61장의 차이맵을 저장했다. 레거시 OK→AI NG 1장, 레거시 NG→AI OK 20장이다. 실제 정답은 미확정으로 유지하며 다음 단계는 사용자 확인이다.

## 불일치 21장 사용자 확인

[라벨 확정 결과](../실험/2026-10-02_JY-METALRING_불일치21장라벨확정_125601.md): 001은 실제 NG, 002~021은 실제 OK. 확인 21장 기준 AI 오탐·미탐 0장, 레거시 오탐 20장·미탐 1장이다. 나머지 7,172장은 미확정이다. 이전 미확정 집계 이후의 후속 확인이다.

## 촬영 일자별 레거시 오류 재집계

[확인 라벨 기준 일자별 집계](../실험/2026-10-02_JY-METALRING_레거시일자별확인오류_125738.md): 레거시 오탐 351장·미탐 9장. 확인 2,348장, 미확정 53,416장이며 전체 오류율은 계산하지 않았다.

## 전체 라벨 확정 후속 결과

[사용자 전체 육안 확인](../실험/2026-10-02_JY-METALRING_전체라벨확정_130128.md): 평가 대상 55,764장 모두 확인 완료, 미확정 0장. 이전 개별 정정을 유지했다. 레거시 오탐 351장·미탐 9장, 전체 대비 오류율 0.646%. 이전 미확정 집계는 당시 기록으로 보존한다.

## CPU 클라이언트 실제 실행 검증

[과거 오류 45장 재생](../실험/2026-10-02_JY-METALRING_CPU클라이언트오류45장재생_131432.md): 동일 EXE에서 기존 ONNX는 오탐 43·미탐 2, 새 k=1 ONNX는 45장 모두 정답. 파일 감시·CPU 추론·JPEG SEG·로컬 HTTP 수신을 확인했다. DB·FTP·Spring은 제외했으며 운영 모델은 변경하지 않았다.


## 정식 모델 등록

[표준 등록 기록](../실험/2026-10-02_JY-METALRING_정식모델등록_132726.md): dev DB 새 모델 상태 4 적용, 이전 모델·DB 기록 백업, input/output PTH·ONNX 생성 및 해시 일치 확인. 정식 키 CPU 과거 오류 45장 오탐·미탐 0. 현장 PC 전송은 수행하지 않았다.
