# 진양 철환 앞뒤 판정

철환 앞뒤의 OK·NG 판정과 현장 적용을 다룬다. DinoMatch와 EfficientNet 등 모델 비교, 라벨 정리, 전처리, 오탐·미탐 분석을 이 프로젝트에 모은다. 진공 그리퍼 연구와 공통 Dinopatch 연구는 별도 프로젝트로 관리한다.

## 코드와 데이터 위치

- 프로젝트 ID: `JY-METALRING`
- 저장소: https://gitlab.computermate.co.kr/rnd/ai_jyos_2026
- 코드: `E:/DH/Gitlab/Jinyang2026/ai_jyos_2026/ai_solution`
- 정리 데이터: `D:/datasets/metal_ring`
- 현장 원본 수집 위치: `D:/Jinyang/metalring/IV`
- 실험 원본: 코드 폴더의 `output/experiments`와 `output/reports`

위 경로는 프로젝트 위치를 식별하기 위한 것이다. 데이터·라벨의 내용은 각 실험 시점의 목록과 해시로 별도 고정한다. 모델과 원본 이미지는 이 노트 폴더로 복사하지 않는다.

## 현재 코드와 연구 기록의 범위

2026-10-02 현재 코드의 DinoMatch 기본값은 `weighted_patch_mean_prototype_topk_blend`, `knnK=1`이다. 근거는 `models/vad/algorithms/dinomatch/config.py`다. 코드 반영과 현장 모델 적용은 별도로 기록하며, 이 노트는 현장 적용 완료를 뜻하지 않는다.

[기존 ai_solution 요약](../ai_solution.md)은 이전 85:15 비교 단계의 기록이다. 현재 최종 결론으로 읽지 않는다. 과거 전체 연구를 새 체계로 정리하는 작업과 실험별 원본 결과 대조는 아직 남아 있다.

## 정리할 연구 흐름

1. 기존 현장 모델의 오탐·미탐과 라벨 수정 이력
2. CLS·패치 평균·위치 순서 연결 비교
3. 박스와 전체 이미지, 결합 비중, k 비교
4. 구별력 가중 패치 평균과 k=1 선택 근거
5. 코드 반영, 모델 생성, 빌드, 현장 적용 상태
6. 신규 데이터의 독립 검증

각 단계는 실제 산출물을 확인한 뒤 실험 노트로 작성한다. 기존 평가 데이터에서 조건을 선택한 결과와 독립 검증 결과를 구분한다.
