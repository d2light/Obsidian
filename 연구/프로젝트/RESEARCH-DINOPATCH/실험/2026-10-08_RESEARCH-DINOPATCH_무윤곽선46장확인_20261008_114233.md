# 윤곽선 없는 46장 원인 확인

- 질문: 왜 46장에 윤곽선이 없는가?
- 기존 결과 읽기 분석. 학습/API/원본 변경 없음. screw160=OK41/NG119.
- 윤곽선은 물체 외곽선이 아니라 이상맵 임계값 초과 영역. 정상 CAL64 픽셀 median/q99.5로 정규화한 3개 모델 맵을 평균·3x3 평활화 후, 선택 크롭의 peak가 속한 >1 연결성분을 표시.
- 46장 모두 크롭은 존재하지만 모든 크롭의 peak<=1로 표시 영역이 없음. 빈 크롭 총52개, peak0.2981966734~0.9925115108. 나머지 일부 빈 크롭은 다른 크롭에 윤곽선이 있어 이미지 수준으로는 제외되지 않음.
- 46장 구성: 정상39, 불량7(thread_side4/manipulated_front3). 윤곽선 있는114장: 정상2/불량112.
- Sonnet 기존 오탐8건 전부 이 46장에 포함. 새 정책으로 오탐이 보류로 이동해도 정상 판정 개선으로 해석하면 안 됨. 정상39/41이 보류 대상인 정책이므로 자동 판정률과 보류를 반드시 함께 평가.
- 무윤곽선은 모델 점수가 표시 기준 이하라는 뜻이며 정상 보증 아님. 1.0은 윤곽선 생성 기준이지 VLM 판단 임계값이나 별도 이미지분류 CAL 임계값과 동일한 값이 아님.
- 다음: 물체 내부 전체를 검사하려는 것인지 이상 제안 영역만 검사하려는 것인지 구분하여 설명. 현재 사용자 결정은 이상 윤곽선 내부 한정으로 보존. 새 성능 측정 없음.
- 시각화: 신규 예측 없음; 기존 Q002/Q123 사례에 윤곽선 없이 정상 이미지를 NG로 판단한 결과 보존.
