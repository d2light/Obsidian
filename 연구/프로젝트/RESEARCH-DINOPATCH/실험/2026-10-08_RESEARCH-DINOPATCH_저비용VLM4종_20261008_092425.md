## 공급자 변경·동시 요청 조건
최초 호환성 요청 중 Luna(OpenAI)·Qwen2종(Alibaba)은 ZDR 경로 부재로 HTTP404가 발생했다. 이 3개 요청은 분류 결과가 아니며 최초 모델 폴더에 그대로 보존했다.

Luna는 별도 luna_azure_recovery에서 Azure로만 변경해 deny/ZDR을 유지했다. Qwen2종은 사용자가 이번 공개 MVTec screw 테스트에 한해 ZDR 해제를 승인한 후 qwen_public_recovery에서 실행했다. Alibaba 고정·data_collection:deny·fallback 금지를 유지하고 요청의 zdr만 false로 변경했다. 계정 전체 설정은 변경하지 않았다. Haiku는 처음부터 Vertex global·deny/ZDR 고정이다. 현재 유효 설정은 run.json의 models, 최초 설정은 initial_models에 보존했다.

세 프로세스는 각각 동시4로 실행했으며 중첩 구간 최대 동시요청은12다. 각 프로세스의 전송 오류 재시도는 순차1회다. 따라서 본문 공통 동시4는 각 프로세스의 설정을 의미하며 전체 동시성이 항상4였다는 뜻이 아니다. API 지연은 동일 부하의 통제된 비교가 아니다.

Haiku와 Qwen Flash의 HTTP429는 공급자 공유 풀의 요청 제한이다. 재시도 후에도 남은 오류는 정상이나 불량으로 간주하지 않고 ERROR로 집계한다. Qwen32B의 유효 분류/위치 형식 오류와 JSON 해석 실패도 구분한다. 유효한 분류를 성능 향상 목적으로 재호출하지 않았다.

전체160장 기준 정확도에는 오류·보류가 분모로 포함된다. 특히 Flash는 API 가용성 문제가 크므로 낮은 전체 정답률을 모델 자체의 결함 이해 능력으로 해석하지 않는다. 응답 수신 부분집합만의 정확도 역시 선택 편향이 있을 수 있다.


응답 오류가 많은 모델의 전체160장 정확도는 공급자 가용성까지 포함한 수치이며 모델 분류 능력만의 순위가 아니다. OK/NG 응답 내 정확도와 응답률도 metrics.json에 별도 저장했다. 표의 평균 API 시간은 최종 시도 중 usage가 반환된 응답 기준이며, 오류를 포함한 모든 시도 평균과 p95도 별도 기록했다. 유효 분류의 위치 스키마 오류 건수도 별도 기록했다.
