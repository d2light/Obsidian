# 소수 정상 기준으로 조도 변화에 대응하는 후속 연구 후보

기존 밝은 정상 몇 장을 고정하고 조도가 바뀔 때마다 이미지를 추가하지 않는 것을 목표로 한다. 우선순위는 **경계 비교 개선 → 자기유사도 비교 → 조명 변화 성분을 제거한 특징 비교**다. 아래 18개는 실험 후보이며, 이번 조사에서 새 성능을 측정한 것은 아니다. 과거 전체 연구에서 한 번도 시도하지 않았다는 의미도 아니다. 이번 고정 기준 프로토콜에서 확인할 차이를 명시했다.

## 현재 출발점

직전 실험은 기준 1/3/5장과 별도 밝은 CAL5장, 원본 TEST268장으로 13조건을 비교했다. TEST는 밝음 OK134/NG70, 어두움 OK51/NG13이며 이미 반복 관찰한 개발 세트다. 기준과 CAL은 기존 정상 촬영 그룹에서 분리했다.

경계 잔차 profile_k5가 전체 AUROC97.648974%였지만 정상185장 중 오탐0, 불량83장 중 자동NG19·미탐30·재확인34였다. 어두운 NG13장은 모두 미탐이었다. 밝은 CAL 최대 점수1.871277이 임계값이어서 어두운 NG 점수1.010818~1.323011을 검출하지 못했다. 점수 순위와 실제 임계값 판정을 함께 개선해야 한다.

현재 해석은 정상 형태 다양성, 경계 추출 오류, 조도 의존 점수가 함께 남아 있다는 것이다. AUROC가 높다는 이유로 임계값만 TEST에 맞추지 않는다. 소수 정상만으로 가능한 범위는 실험으로 확인하며 모든 조명·결함을 보장하지 않는다.

## 첫 실험 순서

1. **A1과 A2를 분리 비교한다.** 기존 profile을 기준으로 A1만, A2만, 둘 다를 비교해 폭 정규화와 경계 안정화의 효과를 구분한다. 거친 크기·세밀한 크기 모두 남겨 넓은 결함을 지우는지 확인한다.
2. **B1 MIND를 단독 비교한다.** 같은 기준·CAL·ROI에서 자기유사도 표현만 바꾼다. Otsu 경계 추출 없이도 국소 구조 비교가 되는지 본다.
3. **B3을 기존 DINO 특징에 적용한다.** 원본 특징과 투영 특징을 같은 설정으로 비교하고 제거 차원 수는 FIT 합성 변화만으로 고정한다. 밝은 결함 검출이 악화되면 조도 강건성 개선으로 채택하지 않는다.

이후 B4 FastRecon, A3 정합, A5 기준 합의를 순서대로 검토한다. 모든 후보를 한 번에 결합하지 않는다. C5의 점수 안정성 검사는 각 단계에 공통 적용한다.

## 공통 평가 조건

- 기준5장과 CAL5장을 고정한다. 실제 dark는 기준 추가·학습·임계값 조정에 쓰지 않는다. 필요한 합성 영상은 메모리에서 생성하고 변환 설정과 seed를 기록한다.
- 기준 선택 seed 변경 실험은 별도 강건성 실험으로 구분하고, TEST에서 가장 잘 나온 seed만 채택하지 않는다.
- 개발 TEST268의 전체 및 밝음/어두움 AUROC, 고정 임계값 FP/FN, 재확인 OK/NG, 자동 판정 비율을 함께 기록한다. 재확인은 성공으로 세지 않는다.
- CAL 한 장의 점수 영향, 기준간 거리, 경계 추출 신뢰도를 표시한다. 정상CAL의 폭 차이가 원인인지 추출 오류인지 사례별 확인하되 임의 제외하지 않는다.
- 합성 어둡기·그림자·회전은 민감도 조사다. 자동으로 실제 OK 라벨을 부여하지 않으며 원본 라벨과 변환 정보를 구분한다. 포화·암부 클리핑으로 정보가 사라진 사례는 별도 표시한다.
- 후보 선택에 사용한 개발 TEST 결과와 독립 검증을 구별한다. 정상 기준이 적다는 조건이 새로운 촬영 조건에서 성능을 보장하는 것은 아니다.
- 기존 neural 모델의 FIT224/CAL85 결과와 이번 기준5/CAL5를 동일 데이터 예산 성능으로 표기하지 않는다.
- 모델별 score 분포, 원본/특징 표현/이상맵, 미탐/오탐/재확인 사례를 함께 제공한다. 원본 경로/해시만 참조하고 JPG 보고서와 정확한 수치맵을 유지한다.

## 우선순위를 낮춘 방법

Zero-DCE 재학습, 단순 RGB 분리, Census/Phase 값 직접 비교, 대규모 증강 메모리 추가를 그대로 반복하는 것은 우선하지 않는다. 직전 결과의 실패 원인을 바꾸는 차이가 있을 때만 다시 시도한다. 검사 영상을 정상이라고 가정해 메모리에 자동 편입하는 온라인 적응은 이번 목표에서 제외한다. 광도/정합의 제한된 검사별 추정은 이와 구분한다.

확산 복원과 큰 생성형 VLM을 더 붙이는 방법도 현재 첫 선택이 아니다. 결함 복원·소실 여부와 추가 비용을 별도로 입증해야 한다. 다중 노출·편광·깊이센서는 현재 이미지 몇 장만 사용한다는 범위를 벗어나므로 별도 장기 과제로 남긴다.

## 확인한 참고 자료

- **S1 MIND**: 자기유사도 기반 다중모달 정합 표현. 밝기 자체 대신 국소 구조를 표현한다는 근거이며 산업 불량 성능의 근거는 아니다. [논문 초록](https://pubmed.ncbi.nlm.nih.gov/22722056/)
- **S2 RIFT**: Phase Congruency 검출과 log-Gabor 최대 방향 인덱스 표현을 사용하는 영상 매칭 연구. [원 논문](https://arxiv.org/abs/1804.09493), [RIFT2와 저자 코드 링크](https://arxiv.org/abs/2303.00319)
- **S3 FastRecon**: 소수 정상 지원 특징으로 정규화된 회귀를 수행하는 이상탐지 연구. [ICCV 2023 논문 페이지](https://openaccess.thecvf.com/content/ICCV2023/html/Fang_FastRecon_Few-shot_Industrial_Anomaly_Detection_via_Fast_Feature_Reconstruction_ICCV_2023_paper.html). 이번에는 공식 CVF 검색 본문/초록을 확인했으며 원문 PDF의 세부 구현 검토와 공식 코드 경로 확인은 착수 시 수행한다.
- **S4 AnomalyDINO**: 추가 학습 없는 DINOv2 패치 기반 소수 정상 이상탐지. [원 논문](https://arxiv.org/abs/2405.14529)
- **S5 RegAD**: 정합 기반 few-shot 이상탐지 공식 구현. [저자 저장소](https://github.com/MediaBrain-SJTU/RegAD). 대상 카테고리 외 사전학습 데이터를 재현 조건에 명시해야 한다.
- **S6 Conformal prediction**: 보정 표본 기반 불확실성 해석의 참고 자료. 분포 이동과 작은 표본의 문제를 해결했다고 간주하지 않는다. [저자 튜토리얼](https://arxiv.org/abs/2107.07511)
- **S7 WinCLIP**: CLIP의 window/patch 표현과 소수 정상 참고 영상 활용 연구. [CVPR 2023 논문 페이지](https://openaccess.thecvf.com/content/CVPR2023/html/Jeong_WinCLIP_Zero-Few-Shot_Anomaly_Classification_and_Segmentation_CVPR_2023_paper.html). 이번에는 CVF 검색 본문을 확인했으며 상세 구현은 착수 시 확인한다.
- **S8 ECC 구현**: A3의 비학습 정합 대조군에 사용할 수 있는 OpenCV 공식 API. 조명에 완전히 불변하거나 실패하지 않는다는 뜻은 아니다. [findTransformECC 문서](https://docs.opencv.org/4.13.0/dc/d6b/group__video__track.html)
