# MVTec AD 전체: DINO 정상 검색 + Qwen VLM

## 질문과 변경
검사 이미지와 비교하기 적절한 정상 3장을 자동 검색하는 방식이 전체 15개 카테고리에서 유효한가?
앞선 hazelnut·metal_nut·pill 392장 결과는 그대로 재사용하고, 나머지 12개 카테고리 1,333장을 신규 API 검사했다. 고정 정상 3장 방식이나 기존 검출기를 이번에 다시 학습한 실험이 아니다.

## 데이터·설정
- MVTec AD 공식 폴더의 테스트 전체 1,725장: 정상 467장, NG 1,258장. 원본 보존, 테스트 증강 없음.
- 동일 카테고리 train/good 전체 후보에서 DINOv2-with-registers-base 동결 특징을 추출. RGB 392 정사각 bilinear, ImageNet 정규화, 최종 CLS 768차원 L2 정규화, cosine 상위3. 테스트 라벨·GT를 검색 또는 VLM 입력에 사용하지 않음.
- 기준/검사 이미지는 1024 정사각. 원래 1024인 이미지는 바이트 복사, 다른 크기는 RGB LANCZOS 확대. 모두 원본 정사각 이미지라 종횡비 왜곡 없음. GT는 원래 해상도를 보존하고 결과 표시에서만 사용.
- Qwen3-VL-235B-A22B-instruct, OpenRouter, 동일 프롬프트, temperature0, max_tokens3000, 재시도0. 각 카테고리 첫10장 순차, 나머지 동시4. seed20261007 순서.
- 새 학습·체크포인트 없음. 원격 VLM 추론이며 연속 이상 점수, AUROC, 픽셀 이상맵을 만들지 않는다. 표시된 박스는 VLM이 반환한 위치다.

## 실패·한계·판단
분류 정확도가 낮은 카테고리: screw 81.25%, zipper 86.75%, capsule 89.39%, grid 92.31%, pill 93.41%.
미탐이 많은 결함 종류(확정 OK 오판만): screw/thread_side 14/23, zipper/squeezed_teeth 9/16, capsule/scratch 8/23, screw/thread_top 6/23, zipper/split_teeth 5/18, screw/scratch_head 4/24, screw/scratch_neck 4/25, pill/color 3/25, pill/contamination 3/21, pill/crack 3/26.


- capsule Q007 / test/scratch/012.png: 원본을 화면에서 확인했다. 주황색 영역의 `500` 글자 위에 여러 가는 긁힘이 보인다. 저장된 VLM 답변은 검정/주황색 캡슐, `500` 및 `actavis` 표기가 기준과 일치하고 차이가 없다는 이유로 OK다. 이는 해당 응답과 시각적 관찰의 불일치이며, 모델 내부 사고과정을 증명하는 설명은 아니다. 실행: qwen_capsule_1024dino_top3_20261007_165337. 최종 집계 전 관찰이고 다른 사례에 일반화하지 않는다.

- grid 오탐의 저장된 설명을 확인했다. Q007은 전체가 어둡고 대비가 약하다는 이유, Q010·Q037은 하이라이트·그림자가 약하고 입체감이 덜하다는 이유로 정상 영상을 NG로 판정했다. Q005는 수평 띠, Q075는 스크래치를 주장했다. 이는 VLM의 서술이며 실제 광학 조건을 계측하거나 내부 원인을 증명한 것이 아니다. 미탐 Q036은 glue인데 기준과 무늬·질감이 같다는 이유로 OK다. 실행: qwen_grid_1024dino_top3_20261007_170514.

- screw Q019 / test/thread_side/003.png: 원본과 정답 마스크를 직접 확인했다. 아래쪽 나사산의 불연속적인 모양 및 몸통의 작은 흠집 위치가 GT에 표시되어 있다. VLM은 모양·나사산 패턴·머리 형태·전체 상태가 기준과 일치한다는 이유로 OK를 반환했다. 정상과 전체 형태가 유사하다는 설명이 국소 결함의 검출을 보장하지 않는 사례다. 실행 경로는 suite.json의 screw 항목에 보존한다.

- transistor Q029 / test/misplaced/006.png와 검색된 정상 train/good/110.png를 직접 비교했다. 정상은 리드 끝이 기판 구멍 위치와 맞아 있으나 검사 영상에서는 옆으로 어긋나 있다. VLM은 세 리드가 구멍 있는 기판에 삽입되어 있고 기준과 같다고 서술하며 OK를 반환했다. 물체 식별과 부품-기판의 상대 배치 검사는 별도 과제임을 보여주는 사례다. 실제 삽입 깊이를 계측한 것은 아니며 영상상 정렬 차이를 관찰했다. 실행 경로는 suite.json의 transistor 항목에 보존한다.


단일 실행·이미 탐색한 데이터이며 독립적인 모델 선택 검증이 아니다. 기준 검색이 고정 기준보다 낫다는 인과적 결론은 동일 조건의 반복·대조 실험이 있어야 한다. 카테고리별 표본 수와 불량 비율이 달라 전체 가중 평균과 카테고리 평균을 함께 보고한다. 분류 정확도가 높아도 모든 불량 위치를 정확히 짚었다는 의미가 아니다. 박스 IoU·픽셀 분할 정확도는 이 보고서에서 측정하지 않았다.

API 응답 시간 평균 6.70초, p95 13.29초. 업로드·서버 대기·전체 응답 수신 포함, DINO 검색·이미지 인코딩 제외. 동시 요청·공급자 라우팅·캐시·실행 시간대가 달라질 수 있다. 저장된 usage 기준 전체 비용 $1.7687는 재사용392장 비용도 포함한다. 이번 신규 1,333장 비용은 $1.3634다. usage가 없는 요청은 비용을 확인할 수 없다.

## 결정·다음 단계
카테고리별 오탐·미탐 원본과 선택된 정상 사례를 먼저 검토한다. 특히 미세 결함과 정상 변이에서 기준 검색 오류인지 VLM 판정 오류인지 나눠 후속 실험을 설계한다. 테스트 결과를 보고 기준이나 임계값을 바꾼다면 별도 개발 실험으로 기록하고 독립 검증 데이터를 확보한다. 이번 결과만으로 기존 검출기를 전면 대체하지 않는다.

기존 PatchCore·DINO Patch·회전6k 비교는 앞서 검증한 3개 카테고리 자료로만 유지한다. 전체15개 동일 조건의 기존 검출기 비교를 새로 수행했다고 주장하지 않는다.
