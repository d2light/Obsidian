# 밝은 정상만으로 어두운 실제 환경까지 일반화

상태: 사용자 목표·제약 반영. 신규 실험·코드·모델·분할 변경 없음.

사용자 의도: 실제 밝은 이미지만 이용해서 실제 어두운 이미지도 판정하고 싶다. 실제 어두운 정상으로 조건별 임계값을 맞추는 이전 제안은 이 목표에 맞지 않으므로 현 목표의 우선안에서 제외한다. 이전 제안 노트는 삭제하지 않고 방향 변경 이유를 남긴다.

범위: 실제 밝은 정상 FIT224/CAL85의 기존 역할을 유지한다. 실제 어두운 정상/불량은 학습·보정·조건별 경계 추정에 사용하지 않는다. 밝은 원본만으로 생성한 합성 조도 변화는 후보로 삼는다. 합성 어두움을 사용하면 '실제 어두운 데이터 미사용, 합성 변화 사용'으로 분명히 표기한다. 이는 조도 증강을 실험하자는 앞선 사용자 의도에 따른 해석이며 새로운 성능 결과가 아니다.

검토할 비교: A 기존 Dinomaly / B 학습·보정·추론에 동일한 조명 정규화 / C B에 밝은 FIT에서만 만든 밝기·감마·완만한 공간 조명 변화 증강을 추가. 노이즈 모델은 실제 촬영과의 차이를 고려해 별도 제한된 후보로 둔다. 구조·경계·국소 결함까지 제거하는 강한 정규화는 피하고 효과를 검증해야 한다. 먼저 B의 단순한 효과를 확인하고 C의 추가 기여를 분리하는 방향이다. 구현 설정은 아직 확정하지 않았다.

임계값: 실제 밝은 CAL 또는 해당 CAL에서만 유도한 합성 조건을 사용하는 후보를 구분한다. FIT와 CAL의 원본/파생본을 교차시키지 않는다. 증강된 CAL로 임계값을 높이면 밝은 불량 미탐이 늘 수 있어 밝음/어두움 오탐·미탐·AUROC를 함께 보고한다. TEST 정답을 보고 임계값/증강 강도/정규화 강도를 맞추지 않는다. 모델은 새 run에서 정상 학습부터 비교해야 하며 기존 모델에 추론 전처리만 붙이는 경우 별도 조건으로 명시한다.

근거·한계: 앞선 Dinomaly 어두운 TEST AUROC100과 원점수 간격0.000810은 조건 내부 구분의 가능성을 보여주지만, 밝은 데이터만으로 조도 불변성을 얻었다는 증거는 아니다. 합성 조도는 실제 광원 방향·반사·노이즈·압축과 다를 수 있다. 심한 암부 손실/포화로 결함 정보가 사라진 경우 정상으로 단정하지 않고 보류할 필요가 있다. 이미 관찰한 TEST로 방법을 논의하므로 현재 데이터는 개발 평가이며 완전히 새로운 일반화 주장은 새 날짜/그룹의 평가가 필요하다.

결정/다음 단계: 조건별 실제 어두운 CAL 확보보다 밝은 원본 기반 정규화·증강의 일반화 가능성을 우선 검토한다. 성공 기준은 어두운 정상의 오탐 감소와 실제 불량 검출 유지이다. 이번에는 제약과 비교 방향만 기록했으며 성능 개선은 아직 측정하지 않았다.
