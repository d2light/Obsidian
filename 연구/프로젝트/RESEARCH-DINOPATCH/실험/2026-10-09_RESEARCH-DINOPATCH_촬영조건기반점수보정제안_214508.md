# 촬영 조건을 함께 사용하는 점수 보정 제안

상태: 사용자 아이디어에 대한 설계 논의. 신규 학습·추론·보정·전처리 구현 없음. 성능 개선은 미검증.

질문: 이상 점수에 밝기 등 상황 정보를 더하면 정상/불량을 다차원 공간에서 구분할 수 있는가?

근거: 기존 Dinomaly 워터씰은 밝은 정상 CAL85/FIT224, TEST 밝은 정상134/불량70 및 어두운 정상51/불량13이다. 현재 임계값 0.095551424. 어두운 정상 최대 0.190814391, 불량 최소 0.191624388, 간격 0.000809997. 조건 내부의 순서 분리와 전체 공통 임계값 실패가 동시에 관찰됐다. 이는 조건부 보정을 검토할 근거이며 효과의 증명은 아니다.

제안: (1) 카메라 노출/게인/조명 설정 등 확보 가능한 촬영 메타데이터 또는 고정된 정상 기준 영역의 밝기·대비를 조건 변수 c로 추정한다. 메타데이터 존재 여부는 아직 확인하지 않았다. (2) 정상 보정 표본에서 c별 점수 기준/산포 또는 상위 분위수 경계를 학습한다. (3) Dinomaly 원점수와 조건별 정상 기준의 차이를 사용해 판정한다. 처음부터 위치/회전/배경 등 많은 조건을 모두 학습하기보다 밝기 1변수와 점수의 2차원 관계를 먼저 확인하는 제안이다.

가능한 비교: 기존 고정 임계값 / 밝음·어두움 별 정상 보정 / 연속 밝기에 따른 정상 점수 경계. 조건별로 표본 수가 적으면 복잡한 회귀는 피한다. 보정 범위 밖의 촬영 조건 또는 조건 추정 실패는 정상으로 자동 처리하지 않고 보류로 구분한다.

위험: 결함 때문에 어두워진 부위를 조도 변화로 해석하면 실제 결함을 지울 수 있다. 전체 이미지 평균 밝기는 물체 면적·위치·결함의 영향을 받으므로 곧바로 조도라고 간주하지 않는다. 정상에서도 안정적인 영역/메타데이터를 우선 검토한다. 정상과 불량이 동일한 조건·점수 공간에서 겹치면 상황 변수만 추가해 해결되지 않는다. 어두운 분리 간격이 좁고 불량13장뿐이므로 일반화는 미확인이다.

분할·평가 원칙: 별도의 정상 CAL만으로 조건 경계를 추정하고 TEST 정답으로 경계를 맞추지 않는다. 기존 TEST 정상 일부를 보정에 재사용한다면 새 분할로 명시하고 남은 표본 결과를 과거 전체 TEST와 동일 조건으로 비교하지 않는다. 촬영 그룹을 분리하며 오탐·미탐·보류·조건별 AUROC를 함께 평가한다. 별도 어두운 정상 데이터가 확보되지 않았으므로 아직 실행 계획의 데이터 부분은 미확정이다.

결정/다음 단계: 단일 점수 대신 촬영 조건과의 관계를 활용하는 방향을 제안으로 기록한다. 다음 검토는 밝기/메타데이터 추출 가능성과 독립 정상 보정 표본 확보 여부 확인이다. 사용자와 구체적인 실험 범위를 정하기 전 모델 동작이나 기존 임계값은 변경하지 않았다.
