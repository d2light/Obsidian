# 공통연구 Dinopatch

여러 검사 대상에서 공통으로 활용할 Dinopatch 이상탐지 방법을 연구하는 프로젝트다. 진양 철환의 현장 판정 결과와 별도로 관리한다.

[기존 Dinopatch 연구 현황](../Dinopatch.md)에 현재 결과와 실험 링크가 있다. 해당 노트와 연결된 일지·실험은 다른 세션에서 편집 중이므로 그대로 보존한다. 이 문서는 고정 프로젝트 ID와 기존 기록을 연결하는 진입점이다.

향후 이 프로젝트의 새 실험·일지·첨부는 이 폴더 아래에 기록한다. 기존 결과는 당시 데이터, 학습 정보, 임계값, 원본·합성 구분과 함께 참조한다. 철환 모델의 OK·NG 마스터 비교 결과를 정상 전용 이상탐지 성능과 합산하지 않는다.

Cable 데이터 `datasets/mvtec/cable`을 확인했다.
